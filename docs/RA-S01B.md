# RA-S01B · Dashboard sample adapter

Status: offline adapter implemented; 14 new synthetic test cases submitted, execution pending. No runtime wiring, deployment or provider requests.

[research-snapshot.js](../src/research-snapshot.js) maps the existing overview and per-PR detail responses to the RA-S01 aggregation contract. The caller must pass the original overview (before adding a pinned older PR) and detail list from the same authorized repository selection. Canonical repository identity and PR URLs are checked; a mismatched repository overview is rejected. Missing, duplicate, unavailable, changed-timestamp, changed-state and unbound details become unknown instead of successful. Fallback openedAt derived from updatedAt is not used. Main CI is separate and requires the provider's available merge-commit SHA. Review-round counts remain lower bounds; truncated commit histories are unknown. No extra pinned PR is counted. Coverage reports invalid, duplicate, missing, stale and unbound rows. The list is limited to 30 recently updated PRs, not a census.

The adapter trusts the existing authenticated provider mapping of PR head checks and merge-commit checks; it does not independently authenticate those associations or establish atomic snapshots. Matching updatedAt values do not prove freshness, and the overview fetchedAt is not a per-detail observation timestamp. The next UI integration must retain the original overview, clear state on repository changes, visibly mark stale snapshots/failed refreshes, and avoid additional requests or polling. CI states inherit the existing provider's classification, including neutral/skipped checks in its success category; do not describe them as individual test outcomes. Coverage counts usable rows including unknown-only records; do not treat that count as fully verified data.

Tests in [research-snapshot.test.js](../test/research-snapshot.test.js) cover mapping, fallback dates, unavailable details, changed snapshots, repository isolation, missing heads, merge CI, incomplete checks, lower bounds, pinned/duplicate records and bounded coverage.
