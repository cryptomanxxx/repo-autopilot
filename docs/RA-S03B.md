# RA-S03B · Offline Symphony control-state model

This reference model is not a production control authority. It is not imported by the Worker application or browser. No endpoint, host, transport, command dispatcher, credential, service binding or durable storage is added. Existing touch controls remain disabled. Upstream audit RA-S03A found no dedicated start/pause/stop routes at the pinned revision.

The pure model starts unknown and disconnected. Explicit synthetic host reconciliation requires a new fencing epoch, no outstanding commands, verified disabled dispatch, stopped workers and preserved evidence before a stopped state. Start requires current scoped owner authorization, confirmed operator choice, DARE gate, verified host/control, included capacity, no paid fallback, zero incremental budget, one agent and bounded runtime/retries. A request produces only a hypothetical simulationOnly command record; it cannot execute. Monotonic sequence and matching epoch/command ID prevent stale or duplicate requests and acknowledgements within the model. Start remains starting until running is confirmed. Pause and stop remain requested until disabled dispatch, stopped workers and evidence preservation are confirmed. Stop supersedes pending start/pause and does not require the start-specific cost or DARE gates. It still requires a valid scoped owner permit. Failed commands and disconnection invalidate stop proof. Pending records survive a disconnect in memory; no auto-resume, no merge authority. A fresh epoch requires explicit reconciliation.

## Production prerequisites, not implemented

Trusted host assertions in this model are fixtures, not proof of authorization or actual host state. The production control authority must persist fencing epochs, monotonic sequences, command records, idempotency keys and audit events atomically before effects; prevent reuse across process restart; bind trusted time, authenticated owner/repo/run scope and CSRF protection; serialize commands and enforce stop fencing at the execution host. Reject late starts at the host, not merely late acknowledgements. A stop request must remain deliverable for an authorized scope when start allowance is exhausted. A lost connection requires explicit recovery of actual worker state, and an independent emergency stop mechanism at the host. A fresh epoch cannot itself prove earlier commands are fenced. Preserve original partial evidence with verified archive identities before claiming preservation; no destructive cleanup shortcut. Verify actual stopped processes and disabled dispatch rather than infer from aggregate counts. Enforce runtime/retry/concurrency/cost bounds at the host, not simply as input claims. No live controls until RA-S04 and DARE approval gates pass and actual host/cost/control capabilities are verified.

Twelve synthetic test cases submitted; local execution and browser testing not claimed. Next: offline safety/cost gate design and eventual durable host-control qualification. No new paid service or live execution authorized.
