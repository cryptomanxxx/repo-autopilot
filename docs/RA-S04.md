# RA-S04 · Offline cost and safety gate

Zero Additional Cost Policy: SEK 0 incremental monetary cost beyond existing subscriptions/services. Unknown is not zero. No purchases, trials, paid fallback, account switching or overage exposure. This pure reference model is not a production enforcement mechanism and is not imported by the application or command model.

The policy and observations must bind repository and run identity, approved one-agent scope, finite runtime/retry limits and expiry. Synthetic trusted-host claims must cover current actual additional spending (zero), disabled paid fallback, durable evidence readiness, control capability and service-specific remaining/required included capacity with hard overage prevention for Codex, GitHub, Cloudflare and host. Observations expire after 60 seconds; individual service claims and policy have separate expiry. The interval is a conservative prototype choice, not a provider guarantee. Units are not converted across services. Missing, stale, wrong-scope, expired or unknown data blocks eligibility. Runtime at the limit, agent-count violation and retry count above approved limit block; a retry at the limit must not schedule another retry. Required capacity must be positive and available in each service. Active runs with blockers yield a simulated safe-stop recommendation, never proof of stopping. A valid fixture only yields eligible_in_simulation, with dispatchAuthorized always false. No actual usage data is collected.

Production requires authenticated, independently evidenced account-specific capacity and billing protections; numeric claims alone cannot guarantee costs. Enforce reservations and consumption atomically before each effect, with durable per-service counters, runtime and retry fencing, independent host watchdog, stop authority even at exhaustion, and safe archival of partial results. Distinguish initial start, continuation and retry; no extra worker starts while active. Reconcile after restart or connectivity loss. Preserve evidence without relying on paid fallback; if preservation cannot be confirmed, mark it unknown. The model neither issues a permit nor implements these mechanisms. No actual provider API, polling, credentials, deployment or new subscriptions. Eleven synthetic tests submitted; local execution not claimed.
